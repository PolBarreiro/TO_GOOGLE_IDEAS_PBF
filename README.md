# Proposals for Google

## Course-Aided Map Orientation

A small Python concept demo proposes using recent GPS course as an additional cue to stabilize the map's forward-facing blue direction indicator when a user holds the phone upright and points it forward.

- [Read the proposal and limitations](Google_Maps_Course_Aided_Orientation/README.md)
- [View the Python demonstration](Google_Maps_Course_Aided_Orientation/heading_demo.py)
